makesPDF

Download GitHub Markdown files as PDF. Open any .md file on GitHub and press Download PDF.

Stored in this browser only, never synced. Anonymous renders work without a key (stricter limits, nothing stored). Create an API key.

Privacy

To render a PDF, the Markdown text of the file you export — including any relative images embedded in it — is sent to makesPDF. Anonymous renders are not stored. Renders made with an API key are kept as a 7-day artifact on your account. No other page data leaves your browser.
